# Raiun privacy notices

Privacy and local-storage behavior depend on the app and platform. Read the notice for the version you use.

- [Android privacy notice](apps/android/PRIVACY.md), including server access, credentials, encrypted storage, backups, scanner processing and external-app handoff.
- Desktop is still developed separately. Its reviewed privacy notice must be included when its source is imported and before a desktop release from this repository.

This layout change does not change Android permissions, application ID, local storage or network behavior. See [Security](SECURITY.md) for private reporting.
