# Raiun 0.9.3 beta

A quick fix for uploads getting stuck on “Verifying transfer” even though the files were missing on the server.

Retrying now safely uploads the missing files. If you have stuck or failed uploads, open Uploads and use **Retry eligible uploads** if needed. This fix has been tested with the affected photo backup.

Install over your current version to keep your accounts and settings. Still a beta, so please let me know if you find any issues.

Download the APK below. `SHA256SUMS` is included to check the download.
