# Raiun Android 1.1.0

Raiun 1.1.0 adds:

- In-app update checks with stable and beta channels, plus optional downloads on unmetered Wi-Fi. Downloads are verified before Android's installer asks you to confirm installation.
- A bulk action to cancel all conflicting uploads for the current account, without deleting files or stopping other transfers.
- More reliable encrypted upload recovery when a completed file takes time to appear on the server.
- More reliable refreshes of large folders, keeping the previous listing if a refresh fails.
- Security and dependency-check improvements, including cleanup after failed sign-in and protection against stale account discovery.

Install over an existing Raiun release to keep its app data. See the [known limitations](../README.md#known-limitations), [app update guide](APP-UPDATES.md) and [testing guide](TESTING.md) for compatibility details and validation scope.
