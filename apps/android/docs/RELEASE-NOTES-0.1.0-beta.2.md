# OpenCloud Android Next 0.1.0-beta.2

- Complete German interface resources, including scanner capture, editing and export screens.
- Choose System default, English or Deutsch under Settings → Appearance → Language. Android 13 and newer also expose the choice in system app-language settings.
- Appearance now has its own submenu, grouping theme/language separately from file size, modification date, extensions and hidden-file controls.

- Security lock controls now use the same rounded settings cards and theme-aware background as other settings.

Android 8.0 or newer, arm64-v8a or x86_64. Signed with the same release identity as beta.1.
