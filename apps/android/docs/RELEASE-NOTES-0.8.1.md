# Raiun 0.8.1

You can now open Details and tap Activities to see changes to a file or folder, like in the web app. This works with Personal files, Spaces and shared items.

- Shows the most recent changes first, with dates and names.
- Refresh checks for new activity. Back to details returns to the item.
- Shows up to 200 recent activities. What you can see depends on the server and your access.

This is still a beta release. Install over your current Raiun version to keep your account and settings. Existing limitations still apply, including no support for end-to-end encrypted Spaces.

Download the APK to install. SHA256SUMS is included to verify the download. GitHub provides the source downloads below.
