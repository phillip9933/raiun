# Raiun Android 1.3.0

- Create and manage OpenCloud guest invitations for files and folders. Recipients open the invitation in their browser.
- Find server connection options more easily with Wi-Fi & certificates settings, and use account colors and clearer account identity in the refreshed interface.
- Browse, copy and move large folders more smoothly, with improved encrypted-folder offline access and transfers.
- Choose **Remember on this phone** for encrypted folders and Spaces on supported Android 15+ devices. The vault password is not saved; **Ask every time** remains available.
- Sign in using the server's configured Android client ID and scopes, including custom scopes used for group access.

Encrypted offline metadata and the database format changed in this release. Older app versions cannot read the new format, and downgrading is not supported. Keep the encryption password as your recovery method. See [known limitations](../README.md#known-limitations) and [privacy](../PRIVACY.md).
