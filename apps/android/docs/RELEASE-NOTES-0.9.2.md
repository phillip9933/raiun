# Raiun 0.9.2 beta

A small update to make backups easier to manage.

- Added file and folder exclusions, like `*.tmp` and `.thumbnail`.
- Cleaned up backup settings and made date folders easier to set up.
- Added a pause option and a button to retry failed uploads. Conflicts still need your choice.
- Fixed the bouncing backup screen and accidental swipe dismissal.

Still a beta, so please let me know if you find any issues. Install over your current version to keep your accounts and settings.

Download the APK below. `SHA256SUMS` is included to check the download.
